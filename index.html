01 Duopra: From Full-Duplex Conversation to Full-Duplex Agency Voice agent · Full duplex

Duopra learns turn-taking and task execution jointly in full-duplex speech, including when to invoke tools and how to revise arguments when the user corrects a request.

Unified action interface
Direct tool calls and backend delegation use the same action interface. When delegating, the model treats the backend as a tool and passes it a self-contained natural-language request.
Three-stage training
Protocol supervised fine-tuning teaches the action format, and full-duplex reinforcement learning rewards timely, complete execution. After the thinker is updated, projector-only training repairs the talker’s conditioning.
Benchmark results
On Full-Duplex-Bench v3, Pass@1 rises from 4.7% to 44.7% with the same backend. Duopra reaches 47.7% with direct tool calls and 49.3% with a DeepSeek backend.
  • Streaming audio
  • Tool calling
  • Full-Duplex-Bench
