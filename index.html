01 MacKit macOS · Swift / SwiftUI

A native macOS toolkit for switching windows, customizing the desktop, and speeding up everyday tasks.

Windows and Finder
Switch windows using thumbnail previews and move files in Finder with ⌘X and ⌘V.
Desktop and device
Import local videos as dynamic wallpapers, check media and calendar events in the notch, or temporarily lock input for cleaning.
Platform and permissions
Built with SwiftUI. Keyboard and window utilities request Accessibility access as needed, and thumbnails use Screen Recording. The native wallpaper extension requires macOS 26.

03 ZhiXing ActHub HarmonyOS NEXT · ArkTS / ArkUI

A team project for SJTU’s NIS3366 course that brings scheduling, tasks, focus timers, and quick notes into one workspace.

Interaction and system integration
Organize tasks with cards and swipe actions, undo deletions, and use system notifications, Calendar, and LiveView.
Local-first data
An ORM and repository layer keep data separate per user. Selected notes can also be sent to an AI chat.
From design to prototype
A six-person team built the course prototype in two weeks. ArkUI powers five main screens with shared cards, overlays, and feedback components, plus light and dark themes.

  • LiveView

01 Duopra: From Full-Duplex Conversation to Full-Duplex Agency Voice agent · Full duplex

Duopra is a research project on full-duplex voice agents that can call tools while listening and speaking.

Recorded demos
Follow recorded sessions on a timeline to see when speech, user corrections, and tool calls occur.
Method and evaluation
The project page explains asynchronous tool execution and shows conversation and tool-use results on Full-Duplex-Bench.
Corrections mid-conversation
In one recorded session, the user changes a value halfway through the request. The agent sends the corrected argument to the tool while keeping the voice session going.

  • Tool calling
  • Full-Duplex-Bench
